# Gonarra

Gonarra is an audio-first mobile guide for discovering Da Nang through curated stops, local stories, and location-aware experiences.

Built with React Native, Expo, TypeScript, and Expo Router. The current product slice includes the branded splash and first onboarding screen.

## Getting started

```bash
cd apps/mobile
npm ci
npx expo start --go
```

Press `a` for Android, `i` for iOS, or `w` for web. To create a native development build, run `npm run android` or `npm run ios`.
