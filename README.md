# Gonarra

Gonarra is a mobile tour guide for discovering Da Nang through curated stops, local stories, and audio experiences.

Built with React Native, Expo, TypeScript, and Expo Router. The current implementation includes the splash and onboarding experience.

## Run locally

```bash
cd apps/mobile
npm install
npm run ios
```

Use `npm run android` or `npm run web` for the other supported platforms. Product and technical documentation lives in [`docs/`](docs/00-INDEX.md).
