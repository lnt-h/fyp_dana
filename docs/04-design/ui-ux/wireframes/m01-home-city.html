Specification notes

Purpose and persona goal

Tom and Linh pick one of the five cities and find a place by Vietnamese name, English name or unaccented alias (US-001).

Components

Built: HomeMapBackdrop, HomeTabBar, avatar button, search field, Action (primary/secondary). New: CityChip, CitySheet, SearchResultRow, EmptyState, Banner (offline).

Interaction

City chip → sheet (radio group, Done). Typing searches after 300 ms debounce; results show at most 20, target in first 5 (AC-001). Tap result → SCR-033 Place card. Plan a trip → SCR-022 (or SCR-040 for guests).

States

StateTreatment
LoadingThree skeleton rows under the search field; status text “Đang tìm… / Searching…” announced politely.
EmptyAs shown: names the city and suggests other spellings or changing city.
ErrorBanner “Không tìm được lúc này. Thử lại / Search is unavailable right now. Try again”; map stays usable.
OfflineAs shown.
BlockedSCR-040 for private features.
Long contentLong names wrap to 2 lines; the other-language name wraps below; no truncation (NFR-024).

Accessibility (WCAG 2.1 AA)

Search field has a visible label via aria-label and placeholder in both locales; result count announced via role=status; every target ≥ 44×44; city sheet is a modal dialog with focus trapped and returned to the chip on close; text contrast ≥ 4.5:1 using --textMuted #5E7585 (README §10).
