Specification notes

Purpose and persona goal

The curator completes bilingual, sourced content and publishes only complete places.

Components

AdminShell, EvidenceTable (one row per field: VI, EN, source, licence, verified date, state, action), PublishPanel, AlertDialog. Field editor (drawer) follows the built Field style (radius 17, 1.5 px border).

Interaction

Edit → field drawer with VI and EN inputs, source picker, licence, verified date, or “unknown with source”. Confirm marks an AI draft as reviewed. Publish → POST admin/places/{id}/publish (expectedRevision, Idempotency-Key).

States

StateTreatment
LoadingSkeleton table.
EmptyNew candidate: all rows “Missing”.
UnknownAllowed when sourced (US-005 AC3).
StaleFacts verified > 180 days flagged.
Error409 → “Đã có người sửa / Changed elsewhere, reload”.
BlockedPublish disabled with named items.

Accessibility (WCAG 2.1 AA)

Evidence table has row headers (field) and column headers; publish blockers listed as text, not only red; dialog traps focus; keyboard-only path: Tab to Edit/Confirm in each row.
