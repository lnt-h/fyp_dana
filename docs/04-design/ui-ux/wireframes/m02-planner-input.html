Specification notes

Purpose and persona goal

Tom or Linh describes a 1–3 day single-city trip by text or form and gets a proposal within the MET-002 budget.

Components

Built: Field, Action, chip (TravelPreferences). New: SegmentedControl, Stepper, Banner, ChatBubble, ProgressSteps, Skeleton.

Interaction

Create proposal → POST plan-previews with Idempotency-Key → SCR-023 (SSE progress) → SCR-024. Cancel returns to the form with input kept.

States

StateTreatment
LoadingSCR-023.
EmptyText box empty: Continue disabled with hint “Mô tả chuyến đi hoặc dùng Biểu mẫu / Describe your trip or use the form”.
ErrorSCR-023 error; field-level errors inline with aria-invalid.
OfflineBanner; Create proposal disabled with reason.
BlockedGuest → SCR-040.
Long contentRequest text up to 500 characters (ASM-060); counter shown from 400.

Accessibility (WCAG 2.1 AA)

Every field has a visible label; error text is linked to its field and announced; disabled action states its reason in text; progress uses aria-live=polite; steppers have − and + buttons ≥ 44 px with value announced.
