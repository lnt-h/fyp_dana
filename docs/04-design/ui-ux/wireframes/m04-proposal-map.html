Specification notes

Purpose and persona goal

Tom pictures the day spatially and checks that walking legs are reasonable.

Components

react-native-maps MapView (Google provider on Android), numbered MapPin (default, selected, blocked), RoutePolyline, StopCard (selected), LegRow, Previous/Next buttons.

Interaction

Tap pin → select stop and scroll the timeline to it. Previous/Next step through stops without touching the map (keyboard and switch access). Fit button frames all stops.

States

StateTreatment
LoadingMap placeholder with skeleton card.
EmptyDay with no stops: city centre and “Ngày này chưa có điểm dừng / This day has no stops yet”.
UnknownPin at place position when entrance unknown.
ErrorTiles fail → banner, timeline link.
OfflineAs shown.
BlockedRed pin + legend text.

Accessibility (WCAG 2.1 AA)

Map is supplementary: every fact on it is also in the timeline (WCAG 1.1.1 alternative). Pins are buttons with “Stop n, name, time”. Previous/Next give a non-gesture path (2.5.1). Required map attribution stays visible (AC-047).
