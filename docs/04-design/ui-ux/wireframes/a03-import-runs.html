Specification notes

Purpose and persona goal

The curator checks that an import ran, what it created and why it failed.

Components

AdminShell, DataTable, DetailPanel, Banner, code hint. Read-only page.

Interaction

Row click → detail panel. “New candidates” count links to SCR-102 filtered by run. No Start button: ingestion is CLI-only (DEC-009); a listing endpoint is not yet in the blueprint interface view (OQ-067).

States

StateTreatment
LoadingSkeleton rows.
EmptyAs shown.
ErrorBanner with code and request ID.
RunningBadge “Đang chạy / Running” with started time; a Refresh button reloads the list (no auto-polling).
PermissionAs SCR-102.

Accessibility (WCAG 2.1 AA)

Numeric columns right-aligned in build; table caption explains read-only; failure reason in text plus code.
