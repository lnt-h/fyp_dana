Specification notes

Purpose and persona goal

Tom looks for a stay for the same city and dates without re-entering his trip (SC-03).

Components

Built: sheet + handle (home.tsx:221-243), Action (secondary). New: PartnerRow, PrefillBadge, PriceRow.

Interaction

Tap partner → open external browser with prefilled deep link from GET trips/{id}/handoffs. No in-app booking or payment (DEC-001 Won't).

States

StateTreatment
LoadingTwo skeleton partner rows.
EmptyAs shown.
ErrorSame as empty with Try again.
OfflineRows disabled: “Cần kết nối / Connection needed”.
BlockedOnly for saved trips; on an unsaved draft the entry is hidden.

Accessibility (WCAG 2.1 AA)

External links announced as “mở trang ngoài / opens external site”; prices include currency in words for screen readers; sheet focus management as other sheets.
