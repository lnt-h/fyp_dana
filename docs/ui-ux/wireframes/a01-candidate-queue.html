Specification notes

Purpose and persona goal

The curator (owner) finds the next candidate to review and tracks progress to 30 places per city.

Components

Admin SPA (React + Vite) reusing mobile tokens as CSS variables (README §6). New: AdminShell (sidebar, top bar), DataTable, FilterBar, KpiTile with meter, Badge.

Interaction

Row click → SCR-103. Filters update the URL query (shareable, back-button safe). Coverage tile click → filter by city.

States

StateTreatment
LoadingAs shown.
EmptyAs shown.
ErrorAs shown.
PermissionAs shown.
Long contentNames wrap; table scrolls horizontally below 1280 px (not a supported width).

Accessibility (WCAG 2.1 AA)

Table has caption and scoped headers; sidebar is a nav landmark with aria-current; every control reachable by Tab with visible focus ring (3 px --tealText); status badges carry text.
