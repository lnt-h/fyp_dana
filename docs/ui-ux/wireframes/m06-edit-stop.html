Specification notes

Purpose and persona goal

Tom adjusts the plan to his own choices (SC-01 step 4: move the museum to the morning).

Components

Sheet, Stepper (15-minute steps, ASM-061), SegmentedControl, Action (small secondary), PlacePickerRow, AlertDialog.

Interaction

Apply → PATCH preview with expectedRevision and Idempotency-Key → SCR-024 recalculating state. Lock (Should; cut order 4) hides when the feature flag is off.

States

StateTreatment
LoadingApply shows “Đang áp dụng… / Applying…” and is disabled.
EmptyPicker with no results: “Không có địa điểm phù hợp ở Hội An / No matching places in Hội An”.
ErrorAs shown; 409 conflict → “Bản nháp đã thay đổi ở nơi khác / This draft changed elsewhere”, reload keeps pending edit.
OfflineApply disabled with reason.
BlockedLock unavailable when flag off; Move to day n hidden for 1-day trips.

Accessibility (WCAG 2.1 AA)

Sheet is a modal dialog with heading; stepper value announced (aria-live); every action has a text label; destructive action uses alertdialog and is not the default focus.
