Specification notes

Purpose and persona goal

Linh, on site in Huế, shows the driver where to go and finds the entrance (SC-02).

Components

MapPreview, DriverPanel (deepOcean, white text 13.79:1), FactRow, SourceLine, Badge (stale), ActionBar. Built: Action.

Interaction

Directions → device maps app with entrance coordinates if verified, else place position (US-023). Ask the Guide → SCR-034 scoped to this place. Find activities → SCR-037 (activities). ＋ adds to the current draft (SCR-028 rules).

States

StateTreatment
LoadingAs shown.
Emptyn/a (a card always has at least names).
UnknownAs shown.
StaleAs shown.
ErrorNot found / unpublished → “Địa điểm này không còn khả dụng / This place is no longer available” (US-003 AC2).
OfflineCached card for saved-trip stops with “Ngoại tuyến · cập nhật lúc … / Offline · updated …”; live hours row hidden.
Long contentDriver panel text scales with system font; no truncation (NFR-024).

Accessibility (WCAG 2.1 AA)

Driver panel is large text (≥ 18 px) for showing across a car; facts are a definition list (k/v); source lines are text, not icons only; live vs. curated data distinguished in words.
